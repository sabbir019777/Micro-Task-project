# 🚀 MicroTask Pro - Micro-Tasking & Earning Platform

**MicroTask Pro** একটি প্রফেশনাল মাইক্রো-টাস্ক প্ল্যাটফর্ম যেখানে ইউজাররা ছোট ছোট কাজ সম্পন্ন করে কয়েন অর্জন করতে পারে এবং সেই কয়েন ডলারে কনভার্ট করে উইথড্র করতে পারে। এখানে বায়াররা টাস্ক পাবলিশ করতে পারে এবং এডমিন পুরো সিস্টেম পরিচালনা করে।

### 🌟 Key Features (10 Bullet Points)
* **Role-Based Dashboards:** Worker, Buyer, এবং Admin-এর জন্য সম্পূর্ণ আলাদা ও সিকিউর ড্যাশবোর্ড।
* **Dynamic Coin System:** রেজিস্ট্রেশনের সময় ওয়ার্কার (১০) এবং বায়ার (৫০) বোনাস কয়েন পায়।
* **Secure Payment Integration:** Stripe API ব্যবহার করে বায়ারদের জন্য কয়েন পারচেজ সিস্টেম।
* **Task Management:** বায়াররা টাস্ক অ্যাড, আপডেট ও ডিলিট করতে পারে (ডিলিট করলে কয়েন ইনস্ট্যান্ট রিফান্ড হয়)।
* **Real-time Notifications:** কাজ অ্যাপ্রুভ, রিজেক্ট বা উইথড্রাল সাকসেস হলে সাথে সাথে নোটিফিকেশন সিস্টেম।
* **Top Workers Showcase:** হোমপেজে সবচাইতে বেশি কয়েন অর্জনকারী ৬ জন ওয়ার্কারের লাইভ ডাটা ডিসপ্লে।
* **Worker Withdrawal System:** ২০ কয়েন = $১ হিসেবে মিনিমাম ২০০ কয়েন হলে উইথড্র রিকোয়েস্ট করার সুবিধা।
* **Interactive UI/UX:** Swiper.js স্লাইডার, Framer Motion অ্যানিমেশন এবং DaisyUI দিয়ে তৈরি আধুনিক ডিজাইন।
* **JWT Authentication:** প্রতিবার লগইনে সিকিউর এক্সেস টোকেন এবং প্রাইভেট রাউট প্রোটেকশন।
* **Responsive Design:** মোবাইল, ট্যাবলেট এবং ডেস্কটপ—সব ডিভাইসের জন্য ১০০% রেসপনসিভ লেআউট।

### 🛠️ Technology Stack
- **Frontend:** React.js, Tailwind CSS, DaisyUI, TanStack Query, Axios, Swiper.js, Framer Motion.
- **Backend:** Node.js, Express.js, MongoDB.
- **Authentication:** Firebase Auth & JWT.
- **Payment:** Stripe API.
